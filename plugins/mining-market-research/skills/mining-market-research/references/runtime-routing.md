Mining Market Research applies only to requested research or plugin operations.
Read the matching Skill before substantive work: headlines/news timelines ->
news-analysis; prices/screens/CSV -> market-analysis; concise introductions ->
company-brief; relative comparisons -> company-comparison; full company reports
or report refresh -> company-report; plugin checks/upgrades -> upgrade.
Mixed or ambiguous tasks use the mining-market-research coordinator.

News and price impact use the shared fusion workflow, not disconnected sections.
Gold tags need not mean gold is the main topic. Daily prices cannot establish
intraday causality; align publication time and exchange sessions without inventing
an event date. Unknown totals are not zero; use cursor-only continuation and the
actual export result. Reports default to get_company_report(auto); distinguish
existing report translation from generation_ready research and not_eligible.

Hook injection is routing guidance, not proof a Skill was read. MCP connectivity
does not prove a full plugin was loaded. When Skills are unavailable, follow the
actual tool contract and returned limitations; do not invent workflow completion.
Maintenance failures never block business. No automatic install or permission
expansion. Server update diagnostics do not enable server takeover.
