# Codex native host

Load the shared skills and remote MCP through the native plugin manifest.
Discover tools in the active session; bind the logical tool names in workflows
to the connected Mining Market Research server. Host prefixes may differ from
the configured `mining_market_research` key or retain a historical alias. Do not
guess a callable name or use an unrelated server with a similarly named tool.

Use the available native web capability for live research. If absent, disclose
incomplete evidence; do not fabricate results or silently install a connector.
Present a temporary CSV URL as a download link. Local persistence requires the
user's request and available filesystem permissions.

Read bundled plugin-update-codex instructions only for explicit installation,
update, or diagnostic requests. For ordinary research follow the shared
`update-notifications.md`: native installed inventory plus a six-hour success
cache; only due checks use fixed Git lookup. No hook or automatic installation.
The source plugin is not proof that a running session has reloaded it; test in
a new task after installation. Do not change host permission settings.
